# 🚀 Interactive Learning & Certification Platform

Bu proje, React ve Node.js kullanılarak geliştirilmiş, kullanıcıların eğitim içeriklerini takip edebildiği, quizlere katılabildiği ve sertifika alabildiği bir full-stack web uygulamasıdır.

## ✨ Özellikler

- 🔐 **Güvenli Kimlik Doğrulama:** JWT tabanlı login ve register sistemi.
- 📚 **İnteraktif İçerik:** Adım adım ilerleyen öğrenme modülleri.
- 📝 **Quiz Sistemi:** Konu sonu değerlendirme testleri.
- 🏆 **Sertifikasyon:** Başarı ile tamamlanan kurslar için otomatik sertifika üretimi.
- 🎨 **Modern Arayüz:** Tailwind CSS ile tamamen responsive tasarım.

## 🛠️ Teknolojiler

| Katman | Teknoloji |
| :--- | :--- |
| **Frontend** | React, Vite, Tailwind CSS, Lucide Icons |
| **Backend** | Node.js, Express.js, TypeScript |
| **Veritabanı** | PostgreSQL (Neon DB) |
| **Barındırma** | Vercel (Frontend), Render (Backend) |
